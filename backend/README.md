# TrustShield Backend

This directory contains the Java 21 + Spring Boot backend.

## Responsibilities

- REST APIs
- Authentication and authorization
- JWT security
- Scan management
- AI service integration
- Risk-score aggregation
- Database operations
- Scan history
- Result delivery
